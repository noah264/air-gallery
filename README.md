# AirGallery · 空间画册

直接浏览这台电脑上的图片目录。照片以画册叠放，从中心向外散开；支持连续缩放、平移、组内翻页与本机摄像头手势控制。

当前为 **v0.1.8 可运行原型**：共享 Web 界面与 Electron 桌面壳已搭建，包含六种玻璃背景主题、独立悬浮画册与首页拍手烟花。平台实测与剩余范围见 [实现状态](./docs/IMPLEMENTATION_STATUS.md)。

## 在线体验与下载

- [Web 在线版](https://noah264.github.io/jetson-photo-wall/)
- [macOS / Windows 安装包](https://github.com/noah264/jetson-photo-wall/releases/latest)：macOS 分 Apple 芯片和 Intel，Windows 提供 x64 安装包；同时提供 Web 静态文件与 SHA-256 校验值。

桌面版本为未签名、未经 macOS 公证的预览版，首次打开可能受到系统安全检查。真实手势准确率、大图库性能和 Windows 实机运行仍需验证。

Web 版通过 HTTPS 使用摄像头；推荐 Chrome / Edge 直接选择本机图片目录。图片和摄像头画面在本机处理，不上传。

## 自动发布

推送到 `main` 后，GitHub Actions 运行核心测试、构建和完整浏览器回归，成功后部署 GitHub Pages。仓库 Settings → Pages 的 Source 需设为 **GitHub Actions**。

推送与 `package.json` 版本一致的 `v*` 标签会构建 macOS arm64 / x64、Windows x64 和 Web 压缩包，全部成功后发布 GitHub Release。失败的草稿可通过 Release 工作流的 Run workflow 输入原标签重试；已发布版本需使用新版本标签，避免覆盖下载包。流程见 [.github/workflows](./.github/workflows)。

## 本地启动

需要 Node.js 22.12+、npm，以及支持 WebGL 的现代浏览器。当前验证环境为 Node.js 24、macOS、Chrome。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。首次安装会下载手部识别模型，后续运行从本地加载模型和 WASM。若下载中断，执行 `npm run assets:prepare` 重试。

初次进入显示内置示例。按 **S → 图片目录 → 选择图片目录**，授权读取当前电脑上的文件夹；不会复制或上传照片。

```sh
# 桌面开发模式（首次运行会准备 Electron）
npm run desktop:dev

# 生产版本启动
npm run build
npm run desktop:start

# 生成本机可执行应用目录 / 安装包
npm run desktop:pack
npm run desktop:dist
```

Electron 二进制首次下载可能较慢。在已安装二进制的环境中，可执行 `npx electron-builder --dir --config.electronDist=node_modules/electron/dist` 复用本机 Electron。安装包尚未配置发布签名与自动更新。

## 浏览与手势

| 操作 | 效果 |
| --- | --- |
| 单击画册 | 移至中心，放大并保留边距 |
| 双击画册 / Enter / 点击名称 | 打开画册 |
| 左右方向键 | 切换画册或组内照片 |
| 滚轮 / 触控板捏合、+ / - | 缩放空间或当前图片 |
| 拖动 | 平移空间或当前图片 |
| Esc | 关闭设置或返回空间 |
| 0 | 恢复当前视图 |
| S | 设置；右上角悬停也会显示入口 |
| H | 开启 / 暂停摄像头手势 |
| 单手捏合、拖动 | 选择画册、平移 |
| 单手比 V，保持约 0.6 秒 | 打开中心选中的画册 |
| 单手握拳，保持约 0.6 秒 | 关闭图集，返回空间 |
| 单手持续向镜头比 👍 | 首页和照片页持续生成随机夸奖弹幕雨，松手后停止新增，已有文字落完退出 |
| P | 预览夸奖雨，无需摄像头 |
| 双手捏合并拉开 / 靠近 | 连续缩放 |
| 张开手掌左右挥动 | 切换画册或照片 |
| 首页或照片页，双掌先分开入镜再自然快速拍手 | 首页或当前照片上播放约 7 秒大型多层烟花及升空、爆破、余火音效 |
| F / 查看器烟花按钮 | 首页和照片页均可手动播放烟花，不需要摄像头 |
| 查看器音量按钮 | 开关烟花音效，偏好保存在本机 |

摄像头默认关闭，用户开启后才请求权限；画面不上传、不录像。设置打开时暂停手势对画面的操作。关闭手势会停止摄像头轨道。比 V 和握拳需要单手入镜，进度满后触发一次；移开、移动过大或换姿势会取消，保持同一姿势不会连发。摄像头开启后，左下角显示追踪状态。拍手通过摄像头识别双掌收拢轨迹，支持侧掌与合掌时短暂遮挡，不请求麦克风权限；约 2.2 秒冷却，单次烟花结束后自动清理，翻页或返回即停止，原图不改动。音效由 Web Audio 在本机合成；首次需按键或点击解锁浏览器音频。

首页每本画册有独立相位的轻微漂移与摆动，选中名称跟随移动；放大时限制屏幕位移，保留中央画册与周围的留白。封面加载后才启动悬浮，重绘间隔随渲染耗时增加；打开照片、设置、播放首页烟花、切到后台或开启减少动态效果时停止持续悬浮重绘。

烟花采用日漫花火大会风格：大尺寸三层花冠、粉紫与冰蓝花芯、金色垂柳、10 束错落连发与三束收尾。密集火花预绘为图层，播放时扩散、下坠与渐隐；减少动态效果偏好会降低密度和范围。

夸奖雨会分列错落下落，不拦截照片操作。持续识别到单手 👍 就持续补充随机文字，松手或关闭摄像头后停止新增；已有文字约 5 秒内落完退出。翻页和返回时可继续下雨，打开设置或切到后台会清理；减少动态效果时定时刷新静态夸奖卡片。P 键保留约 8 秒的有限预览。

## 本机目录规则

- 递归读取 JPG、JPEG、PNG、WebP；每个直接含图片的文件夹对应一本画册，根目录图片独立成册。
- 按文件名自然排序，`2.jpg` 排在 `10.jpg` 前；默认用首张作为封面，叠层表示组内还有图片。
- 桌面端保存上次目录并监听变化；异常时可手动刷新。跳过符号链接。
- Web 优先使用目录授权 API，句柄存入 IndexedDB；可见时每 15 秒检查变化，切回窗口时也刷新。浏览器可能要求再次授权。
- 不支持目录授权 API 时，提供文件夹选择兼容模式；刷新页面或目录内容更新后需重新选择。
- 空间位置、缩放和选中画册按来源名称保存；主题支持预览、取消、应用及跟随系统。

Web 的玻璃效果模糊页面内背景，不能读取浏览器后面的桌面。macOS 使用系统 vibrancy；支持条件满足的 Windows 11 使用 acrylic，其他环境保留 CSS 材质。

## 验证

```sh
npm test
npm run test:e2e       # 需要本机 Google Chrome；使用模拟摄像头
npm run build
npm run test:desktop   # 需要 Electron；使用独立临时目录与独立应用配置
```
